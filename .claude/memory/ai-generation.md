# AI generation and polling

- Keep one normalized contract for `taskStatus`, `taskInfo`, `taskResult`, and deeply nested media URLs. Use `extractMediaUrl` for image/video and `extractAudioUrl` for music; never treat an audio cover image as the audio result.
- Async submission must persist the DB task, start foreground polling, and keep background polling for refresh/route changes. Pollers must stop on success, failure, cancellation, timeout, unmount, and route/media changes.
- Never let an older poll overwrite a newer terminal state. Batch polling must query the exact pending IDs and exclude tasks owned by a foreground poller.
- A provider response marked success without a usable media URL is failure and must revoke consumed credits.
- Mock tasks advance through `taskInfo.mockQueryCount`; do not discard mock `taskInfo/taskResult` while status is `processing`, or the counter freezes forever.
- Preserve explicit generation intent only: unauthenticated “Generate” stores a draft; passive page visits must not auto-submit. After auth, consume the draft once, clean the query string, and submit with the saved model/options/images.
- Separate text-to-video, image-to-video, text-to-image, image-to-image, music, and PNG-maker options. Unsupported image models must receive no stale image parameters.
- Always clear the submit loading state in `finally` when mounted, including auto-resume flows and StrictMode/lifecycle races.
- Validate model-specific limits and contracts (max images/2MB, first/last frame pairing, ratio, duration, resolution) at both UI and API boundaries.

## Verified APIMart and KIE contracts (2026-09-03)

- jon has manually verified the current APIMart and KIE image, video, and music integrations. Do not alter their model mappings, request fields, frontend model lists, option values, or conditional control visibility unless a reproducible bug or an upstream API-document change requires it.
- Keep provider-specific request construction in `src/core/ai/apimart.ts` and `src/core/ai/kie.ts`; never restore a shared catch-all payload that sends image, image_urls, first_frame_image, last_frame_image, size, aspect_ratio, duration, resolution, or audio fields indiscriminately.
- APIMart source documentation: image models [GPT Image 2](https://docs.apimart.ai/cn/api-reference/images/gpt-image-2/generation), [Qwen Image 3.0](https://docs.apimart.ai/cn/api-reference/images/qwen-image-3.0/generation), [Seedream 5.0 Pro](https://docs.apimart.ai/cn/api-reference/images/seedream-5-0-pro/generation); video models [Seedance 2.5](https://docs.apimart.ai/cn/api-reference/videos/seedance-2-5/generation), [Wan 3.0](https://docs.apimart.ai/cn/api-reference/videos/wan3.0-video/generation), [Kling 3.0 Turbo](https://docs.apimart.ai/cn/api-reference/videos/kling-3.0-turbo/generation), [MiniMax H3](https://docs.apimart.ai/cn/api-reference/videos/minimax-h3/generation), [Hailuo 2.3](https://docs.apimart.ai/cn/api-reference/videos/minimax-hailuo-2.3/generation), [Wan 2.7](https://docs.apimart.ai/cn/api-reference/videos/wan2.7/generation), [Seedance 2.0](https://docs.apimart.ai/cn/api-reference/videos/seedance-2-0/generation); music [Flow Music](https://docs.apimart.ai/cn/api-reference/audios/flow-music/music) and [Suno](https://docs.apimart.ai/cn/api-reference/audios/suno/generation).
- APIMart image requests use `size`, `resolution`, and `image_urls` only. The APIMart frontend exposes GPT Image 2, Qwen Image 3.0, and Seedream 5.0 Pro; resolution values are GPT `1k/2k/4k`, Qwen `1K/2K`, and Seedream `1K/1.5K/2K`.
- APIMart video image contracts: Seedance 2.5/2.0 and Wan 3.0 use `image_with_roles`; MiniMax H3 uses `first_frame_image`/`last_frame_image`; Hailuo and Kling use only `first_frame_image`; Wan 2.7 uses `image_urls`. Hailuo has no ratio control; image-to-video ratio controls must remain hidden where the input image determines the ratio. Hailuo `1080p` permits only `6s`.
- APIMart music contracts: Flow Music sends `model: flowmusic` with `sound_prompt` (and optional `lyrics`); Suno sends `model: suno`, required `version`, `custom: false`, `prompt`, and `instrumental`. Do not send the KIE-style `sound_prompt` to Suno.
- KIE source documentation: [Seedance 2.5](https://docs.kie.ai/market/bytedance/seedance-2-5), [Seedance 2.0](https://docs.kie.ai/market/bytedance/seedance-2), [Wan 3.0](https://docs.kie.ai/market/wan/3-0-video), [Wan 2.7 text-to-video](https://docs.kie.ai/market/wan/2-7-text-to-video), [Wan 2.7 image-to-video](https://docs.kie.ai/market/wan/2-7-image-to-video), [Kling 3.0 Turbo text-to-video](https://docs.kie.ai/market/kling/v3-turbo-text-to-video), [Kling 3.0 Turbo image-to-video](https://docs.kie.ai/market/kling/v3-turbo-image-to-video), [MiniMax H3 text-to-video](https://docs.kie.ai/market/minimax-h3/text-to-video), [MiniMax H3 image-to-video](https://docs.kie.ai/market/minimax-h3/image-to-video), [Hailuo text-to-video](https://docs.kie.ai/market/hailuo/02-text-to-video-pro), and [Hailuo 2.3 image-to-video](https://docs.kie.ai/market/hailuo/2-3-image-to-video-pro).
- KIE video requests remain model-specific: Seedance/Wan 3/MiniMax H3 use numeric duration; Kling uses string duration; Wan 2.7 uses numeric duration; Hailuo text does not send duration/resolution, while Hailuo image uses string duration. Do not send generic `n_frames` or `size` to KIE video models.

# Genematic AI 配置核查与定价建议

核查日期：2026-10-22。范围：当前代码、正式 Worker `genematicai`、绑定的远程 D1，以及供应商官方公开价格。本次未修改正式售价、支付开关或购买供应商额度。以下建议暂按海外用户和美元收款测算。

## 配置状态

| 项目           | 当前证据                                                                                | 结论                                                       |
| -------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 网站与 HTTPS   | 正式域名可访问；www、旧 Worker 的公开页面永久跳转                                       | 已验证                                                     |
| D1 业务数据库  | Worker 绑定 `genematicai-db`；远程 SQL 可执行；此前注册已验证                           | 已接通，不等同于文件存储                                   |
| 邮件           | Resend Secrets 存在，历史实发已到 Gmail；客服转发已实收                                 | 已验证                                                     |

| AI             | config 中没有供应商密钥；Worker Secret 列表也没有 AI 密钥；ai_task 没有记录             | 未接通、未实测                                             |

| 后台配置加密   | 未发现 `CONFIG_ENCRYPTION_KEY` Secret                                                   | 后续保存供应商密钥前需启用；当前还不能宣称后台密钥均已加密 |

远程 config 当前仅有 `email_verification_enabled` 与 `resend_reply_to` 两条设置。Resend 密钥与发件地址来自 Worker Secrets，因此邮件仍可使用。

`src/routes/api/config/public.ts` 在没有供应商密钥时，也把 `active_ai_provider` 返回为 `kie`。这是默认展示值，不能用作已接通证据。此前根据这一字段判断 KIE 已连接不准确。

Cloudflare 账号已有其他项目的 R2 桶，但“桶存在”不代表本项目已连接，不能擅自复用其中的数据。

## 当前定价的风险

前台当前销售一次性包：$9.99 / 400 积分、$49.99 / 2,500 积分、$99.99 / 6,000 积分。

后端 `src/config/pricing.ts` 还保留模板订阅与 lifetime 商品。例如 `enterprise_monthly` 为 $99 / 500,000 积分，`getPricingProduct` 仍接受这些 ID。它们不是目前前台展示的商品，但在开放支付前需要移除或设置服务端停售状态。不能只隐藏前台入口。

按现有扣费函数与 KIE 公开单价，使用最高档套餐所得积分时：

| 任务                                  | 现扣积分 | 分摊收入 | 上游标价成本 | 判断                        |
| ------------------------------------- | -------: | -------: | -----------: | --------------------------- |
| Wan 3.0，480p，5 秒，无视频参考       |       13 |   $0.217 |        $0.20 | 扣支付手续费前仅余约 $0.017 |
| Seedance 2.5，480p，5 秒，无视频参考  |       45 |   $0.750 |        $0.70 | 余量很薄                    |
| Seedance 2.5，720p，5 秒，无视频参考  |       90 |   $1.500 |       $1.575 | 已低于 API 成本             |
| Seedance 2.5，1080p，5 秒，无视频参考 |      180 |   $3.000 |        $3.95 | 已低于 API 成本             |

收入是该任务消费积分对应的套餐收入分摊，不是单独对该任务再扣一笔固定支付手续费。当前无真实成交成本日志，上游大额充值赠送不作为利润成立的前提。

模型名称也需先校准：当前 `nano-banana-2` 映射到 `nano-banana-2-lite`，`nano-banana-pro` 映射到 `google/nano-banana` 或 edit 版本。应按实际购买的模型命名和定价，不能按展示名称猜测 API 成本。Lite 的公开文档不支持把输出当作原生 2K/4K。

## 建议初始方案

先推出一次性积分包，不急于上线订阅、年付或 lifetime。现阶段复购、成功率、客服负担和真实模型成本均没有生产样本。

| 方案    | 一次性售价 |  积分 | 有效期建议 | 定位     |
| ------- | ---------: | ----: | ---------- | -------- |
| Starter |      $9.99 |   500 | 180 天     | 首次尝试 |
| Creator |     $29.99 | 1,800 | 180 天     | 主推档   |
| Studio  |     $59.99 | 4,000 | 180 天     | 持续创作 |

这是待实施建议，尚未改动实际商品。180 天是积分有效期，不自动代表文件保存 180 天；文件保留策略需要另行实施和明确告知。

### 积分必须同时重新计价

建议把 1 积分作为最多 $0.005 上游成本预算单位，并在每次扣费中预留 15% 的波动与异常成本：

`扣费积分 = 向上取整到 5 的倍数(上游预估美元成本 × 1.15 ÷ 0.005)`

上游预估成本要计入模型、模式、像素、时长、音频、参考视频输入，以及供应商充值手续费；不要使用一个通用分辨率倍率代替供应商实际 SKU。下表仅适用于 KIE 上述明确列出的任务，不适用于所有视频模型。

| 示例任务                    | KIE 成本预算 | 建议积分 | Starter 可完成数量 |
| --------------------------- | -----------: | -------: | -----------------: |
| Nano Banana 2 Lite，1K 一张 |        $0.02 |        5 |             100 张 |
| Wan 3.0，480p，5 秒         |        $0.20 |       50 |              10 条 |
| Seedance 2.5，480p，5 秒    |        $0.70 |      165 |               3 条 |
| Seedance 2.5，720p，5 秒    |       $1.575 |      365 |               1 条 |
| Seedance 2.5，1080p，5 秒   |        $3.95 |      910 |   Starter 不足一次 |

这些是整包只使用同一种任务的理论数量，不是可同时获得的视频和图片数量。不要再宣传固定“最多 X 视频 + Y 图片”而不注明模型参数、混合使用关系。

### 整包成本压力测试

假设全部积分均消耗，按每积分 $0.005 的成本上限预算，以 Creem 公开费率测算：

| 售价   | 最大 AI 成本预算 | 支付手续费估计 | 剩余贡献率 |
| ------ | ---------------: | -------------: | ---------: |
| $9.99  |            $2.50 |          $0.79 |      67.1% |
| $29.99 |            $9.00 |          $1.57 |      64.8% |
| $59.99 |           $20.00 |          $2.74 |      62.1% |

贡献率不是净利润：尚未扣存储、邮件、Worker、客服、税、营销、退款和拒付等成本。15% 预留已经包含在扣费公式中，不能再次把它全部当作新增收益。

建议验证邮箱后一次赠送 20 积分，7 天有效，不每日自动刷新。按 Lite 5 积分/张约可体验 4 张图，上游成本约 $0.08。贵价视频不默认免费；风控和总体验预算要独立限制，邮箱验证本身不能阻止批量注册。

## 供应商选择建议

短期按已写好的 KIE 适配器接入最省开发成本；OpenRouter 可作为候选渠道，不应认为只能处理文字，它也有图片和异步视频接口。当前项目没有实现它对应的生成、轮询、文件下载、错误映射和退款联动。

Seedance 2.5 的 OpenRouter 720p 示例价约 $1.1556/5 秒，算入 5.5% 充值费约 $1.2192；低于 KIE 标价 $1.575。Lite 图片的 KIE 页面价则更有优势。建议按模型比价，而不是全平台盲目只选一家；正式选择还需要同规格生成成功率、耗时、内容限制和实际账单测试。

收款可评估 Creem，但需商户审核、主体支持和产品政策均通过。已经有合规可用的 Stripe 主体时也可使用 Stripe。代码支持并不代表支付账户已开通。开放付款之前必须验证真实订单、签名回调、幂等积分发放及退款扣回。

## 实施顺序

1. 配置后台密钥加密，连接专用 R2 桶和可访问的文件域名，验证上传与下载。
2. 选择供应商，保存密钥，按真实模型 ID 校准标签和参数，实测一张图与一段视频，并核对扣费和失败返还。
3. 更新服务端商品白名单、模型成本表、扣费与价格页，禁售模板商品。
4. 完成商户审核与支付密钥、产品映射、Webhook；真实小额支付并检查积分到账，再验证重放和退款。
5. 上线后按模型统计实际支出、成功率、付费转化、复购与客服成本，再决定订阅是否有必要。
